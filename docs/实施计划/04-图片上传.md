# 阶段 4：图片上传

## 目标

实现图片上传（本地/URL）、查询、编辑、删除与批量抓取。

## 前置依赖

阶段 3（空间与成员权限）。

## 任务清单

- [ ] `picture` 表实体 / Mapper / Service
- [ ] 上传模板 `PictureUploadTemplate` + `FilePictureUpload` / `UrlPictureUpload`
- [ ] `CosManager`（COS 上传 + CI 图片处理：webp、缩略图、宽高/主色调）
- [ ] 分页查询 / 详情 / 编辑 / 删除
- [ ] 批量抓取上传（Jsoup）

## 关键类

- `PictureController`、`PictureServiceImpl`
- `PictureUploadTemplate`、`FilePictureUpload`、`UrlPictureUpload`
- `CosManager`

## 验收标准

- 本地文件上传、URL 上传均可用
- 上传后 COS 有原图/缩略图，CI 图片处理生效
- 分页查询、详情、编辑、删除可用
