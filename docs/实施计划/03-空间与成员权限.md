# 阶段 3：空间与成员权限

## 目标

实现空间 CRUD、空间成员管理，以及 RBAC 细粒度权限控制。

## 前置依赖

阶段 2（用户认证）。

## 任务清单

- [ ] `space` 表 CRUD（创建 / 编辑 / 删除 / 详情 / 列表）
- [ ] `space_user` 成员管理（添加 / 改角色 / 移除 / 列表）
- [ ] 权限配置 `spaceUserAuthConfig.json`
- [ ] 空间权限体系：`StpKit.SPACE` + `StpInterfaceImpl` + `@SaSpaceCheckPermission`
- [ ] 公共 / 私有 / 团队三种场景的权限分支收敛

## 关键类

- `SpaceController`、`SpaceServiceImpl`
- `SpaceUserAuthManager`、`StpInterfaceImpl`、`StpKit`、`SaSpaceCheckPermission`

- 空间权限鉴权生效（viewer/editor/admin 权限正确）
