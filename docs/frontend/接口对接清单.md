# 前端接口对接清单

> 本文档汇总 12 个页面与后端接口的调用关系，用于前后端联调与交叉校验。数据来源为《页面设计》各文档的「接口调用」小节，接口契约以《API 接口文档》为准。

## 一、页面 → 接口映射

| 页面 | 路由 | 调用接口（前端函数 → 后端接口） |
| --- | --- | --- |
| 图片列表 | `/` | `listPictureByPageApi` → `GET /picture/list/page/vo`<br>`deletePictureApi` → `POST /picture/delete` |
| 图片详情 | `/picture/:id` | `getPictureApi` → `GET /picture/get/{id}`<br>`editPictureApi` → `POST /picture/edit`<br>`deletePictureApi` → `POST /picture/delete` |
| 上传图片 | `/picture/upload` | `uploadPictureApi` → `POST /picture/upload`<br>`listMySpaceApi` → `GET /space/list` |
| 登录 | `/login` | `loginApi` → `POST /user/login` |
| 注册 | `/register` | `registerApi` → `POST /user/register` |
| 以图搜图 | `/picture/search` | `searchByPictureApi` → `POST /picture/search/by/picture` |
| 我的空间 | `/space/manage` | `listMySpaceApi` → `GET /space/list`<br>`addSpaceApi` → `POST /space/add`<br>`editSpaceApi` → `POST /space/edit`<br>`deleteSpaceApi` → `POST /space/delete` |
| 空间图片 | `/space/:spaceId` | `getSpaceApi` → `GET /space/get/{id}`<br>`getMySpacePermissionApi` → `GET /spaceUser/get`<br>`listPictureByPageApi` → `GET /picture/list/page/vo` |
| 空间成员 | `/space/:spaceId/members` | `listSpaceUserApi` → `GET /spaceUser/list`<br>`addSpaceUserApi` → `POST /spaceUser/add`<br>`editSpaceUserApi` → `POST /spaceUser/edit`<br>`deleteSpaceUserApi` → `POST /spaceUser/delete` |
| 空间分析 | `/space/:spaceId/analyze` | `getUsageAnalyzeApi` → `GET /space/analyze/usage`<br>`getCategoryAnalyzeApi` → `GET /space/analyze/category`<br>`getTagAnalyzeApi` → `GET /space/analyze/tag`<br>`getSizeAnalyzeApi` → `GET /space/analyze/size` |
| 空间用量排行 | `/admin/rank` | `getSpaceRankApi` → `GET /space/analyze/rank` |
| 用户角色管理 | `/admin/user` | `updateUserRoleApi` → `PUT /user/role` |

## 二、全局 / 布局层接口

以下接口不归属于具体页面，由 `userStore` 统一调用：

| 前端函数 | 后端接口 | 调用方 |
| --- | --- | --- |
| `getLoginUserApi` | `GET /user/get/login` | `userStore.fetchLoginUser`（刷新后恢复登录态） |
| `logoutApi` | `POST /user/logout` | `userStore.logout`（`MainLayout` 顶栏退出） |

## 四、交叉校验结论

### 1. 有前端封装、但无页面使用的接口（2 个）

| 接口 | 说明 | 建议 |
| --- | --- | --- |
| `POST /picture/upload/batch` | 批量抓取上传，前端已封装 `uploadPictureByBatchApi`，但无对应页面 | 并入「上传图片」页作为批量入口，或暂不启用 |
| `GET /picture/search/color` | 按颜色相似度搜索，前端已封装 `searchByColorApi`，但图片列表的 `picColor` 是「精确匹配」（走 `/list/page/vo`），非相似度搜索 | 新增独立「按颜色搜索」页，或并入图片列表高级筛选 |

### 2. 后端代码与《API 接口文档》权限标注不一致（4 个，疑似后端漏权限注解）

| 后端接口 | 代码现状 | 文档标注 | 影响 |
| --- | --- | --- | --- |
| `GET /picture/get/{id}` | 仅 `@SaCheckLogin` | `picture:view` | 空间图片详情可能越权 |
| `POST /picture/search/by/picture` | 仅 `@SaCheckLogin` | `picture:view` | 空间内以图搜图可能越权 |
| `GET /picture/search/color` | 仅 `@SaCheckLogin` | 空间按权限 | 空间内颜色搜索可能越权 |
| `GET /space/analyze/rank` | 仅 `@SaCheckLogin` | 系统管理员 | 排行接口可能被普通用户访问 |

> 以上需后端确认：是「漏加 `@SaSpaceCheckPermission` / `@SaCheckRole` 注解」，还是「在 Service 层做了等价校验」。建议后端逐项核对后修正或补充说明。

### 3. 其他提示

- **用户 ID 输入缺口**：空间成员添加（`spaceUser/add`）与用户角色管理（`/user/role`）均需手动输入 `userId`，后端暂无「按账号查用户」接口，待后端补充后优化。
- **空间图片复用图片列表**：`/space/:spaceId` 与 `/` 共用列表组件，`spaceId` 来自路由参数，权限来自 `spaceStore`。
