# 上传图片页面设计

> 所属路由：`/picture/upload`。配套《前端设计文档》《组件设计文档》《状态管理设计文档》《API 接口文档》。

## 一、页面定位

支持「本地文件」与「网络 URL」两种方式上传图片到公共图库或指定空间，前端做文件类型 / 大小预校验。

## 二、路由与权限

| 项 | 说明 |
| --- | --- |
| 路由 | `/picture/upload` |
| 权限 | 登录 + 目标空间 `picture:upload`（公共图库默认有上传权限） |
| 前置 | 由 `RequireAuth` 包裹 |

## 三、布局与组件树

```
MainLayout
└── PictureUploadPage
    ├── 上传方式切换（本地文件 / URL）
    ├── 目标空间选择（Select：公共图库 + 我的空间列表）
    ├── PictureUploader           # 本地文件选择或 URL 输入
    ├── 图片信息表单（picName / category / tags）
    └── 提交按钮
```

## 四、页面内状态（useState）

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| uploadMode | `'file' \| 'url'` | 上传方式 |
| targetSpaceId | `number \| undefined` | 目标空间（`undefined` = 公共图库） |
| form | `{ picName?: string; category?: string; tags?: string[] }` | 图片信息表单 |
| submitting | `boolean` | 提交中 |

- `tags` 用 `Select mode="tags"` 收集为 `string[]`，提交时转 JSON 字符串。

## 五、接口调用

| 时机 | 接口 | 参数 |
| --- | --- | --- |
| 提交上传 | `uploadPictureApi(FormData)` | `file` 或 `fileUrl`（二选一）、`spaceId`、`picName`、`category`、`tags` |
| 加载我的空间列表 | `listMySpaceApi()` | 无（供目标空间选择） |

## 六、交互流程

1. 进入页面：调 `listMySpaceApi()` 填充空间选择下拉（公共图库 + 私有 / 团队空间）。
2. 选择上传方式：本地文件（`Upload` 选择，`beforeUpload` 校验类型 `jpeg/png/jpg/webp`、大小 ≤ 2MB）或 URL（`Input` 输入）。
3. 选择目标空间：默认公共图库（`undefined`）。
4. 填写可选信息：`picName`、`category`、`tags`。
5. 提交：构造 `FormData`（本地文件用 `file` 字段，URL 用 `fileUrl` 字段；`tags` 转 JSON 字符串）→ `uploadPictureApi`。
6. 成功：`message.success`，跳转图片列表或停留在本页继续上传（可配置）。

## 七、权限显隐

- 上传按钮在公共图库始终可用（`PUBLIC_PERMISSIONS` 含 `picture:upload`）。
- 团队空间需 `picture:upload` 权限，无权限时目标空间选项禁用或提交时拦截（后端兜底返回 `40101`）。

## 八、加载 / 空 / 错误态

- 提交中：按钮 `loading`。
- 文件类型 / 大小不合规：`beforeUpload` 中 `message.error` 并阻止上传。
- 接口失败：拦截器统一提示。

## 九、关键注意点

1. 本地文件与 URL 二选一，提交前校验必须有其一。
2. `tags` 提交前 `JSON.stringify`，与后端「JSON 数组字符串」约定一致。
3. `spaceId` 为空（公共图库）时传 `undefined`，避免误传空字符串。
4. 前端预校验（类型 / 大小）减少无效请求；后端仍会做最终校验。
