# 以图搜图页面设计

> 所属路由：`/picture/search`。配套《前端设计文档》《组件设计文档》《状态管理设计文档》《API 接口文档》。

## 一、页面定位

上传查询图（本地文件或网络 URL）检索视觉相似图片，以栅格列表展示相似结果。

## 二、路由与权限

| 项 | 说明 |
| --- | --- |
| 路由 | `/picture/search` |
| 权限 | 登录 + `picture:view`（公共图库默认有） |
| 前置 | 由 `RequireAuth` 包裹 |

## 三、布局与组件树

```
MainLayout
└── PictureSearchPage
    ├── 查询区
    │   ├── 查询图上传（Upload：本地文件 / URL 输入，二选一）
    │   ├── 空间选择（spaceId，可选）
    │   └── topK（返回数量，默认 20）
    ├── 搜索按钮
    └── 结果区（Row / Col）
        └── PictureCard × N（相似图片）
```

## 四、页面内状态（useState）

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| queryFile | `File \| null` | 查询图本地文件 |
| queryUrl | `string` | 查询图 URL |
| spaceId | `number \| undefined` | 限定搜索空间（可选） |
| topK | `number` | 返回相似数量，默认 20 |
| resultList | `PictureVO[]` | 相似图片结果 |
| loading | `boolean` | 搜索中 |

## 五、接口调用

| 时机 | 接口 | 参数 |
| --- | --- | --- |
| 点击搜索 | `searchByPictureApi(FormData)` | `file` 或 `fileUrl`（二选一）、`spaceId`（可选）、`topK` |

## 六、交互流程

1. 选择查询图：本地文件（`Upload` 选择，校验类型 / 大小）或输入 URL。
2. 可选：选择限定搜索空间、调整 `topK`。
3. 点击「搜索」→ 构造 `FormData` → `searchByPictureApi` → 填充 `resultList`。
4. 结果以栅格展示 `PictureCard`，点击卡片跳转 `/picture/:id`。

## 七、权限显隐

- 公共图库所有登录用户可用（`picture:view` 在 `PUBLIC_PERMISSIONS`）。
- 空间内限定搜索时，需目标空间 `picture:view`。

## 八、加载 / 空 / 错误态

- 搜索中：按钮 `loading` 或 `Spin`。
- 无结果：`Empty`，文案「未找到相似图片」。
- 查询图类型 / 大小不合规：前端校验拦截提示。

## 九、关键注意点

1. 查询图与 URL 二选一，提交前校验必须有其一。
2. `file` 使用 `FormData` 提交，与上传接口一致。
3. `topK` 默认 20，与后端默认值一致。
4. 结果复用 `PictureCard` 展示，避免重复实现。
