# 空间成员页面设计

> 所属路由：`/space/:spaceId/members`。配套《前端设计文档》《组件设计文档》《状态管理设计文档》《API 接口文档》。

## 一、页面定位

管理团队空间的成员：添加成员、修改成员角色、移除成员。仅空间管理员（`spaceUser:manage` 权限）可操作。

## 二、路由与权限

| 项 | 说明 |
| --- | --- |
| 路由 | `/space/:spaceId/members` |
| 权限 | 登录 + 空间 `spaceUser:manage`（仅 `admin` / 创建者） |
| 前置 | 由 `RequireAuth` 包裹；进入前校验 `hasPermission('spaceUser:manage')` |

## 三、布局与组件树

```
MainLayout
└── SpaceMemberPage
    ├── 空间头部（返回）
    ├── 成员表格（Table）
    │   └── 列：账号 / 昵称 / 头像 / 角色 / 加入时间 / 操作
    ├── 「添加成员」按钮
    └── MemberFormModal（添加 / 修改角色弹窗）
```

## 四、页面内状态（useState）

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| memberList | `SpaceUserVO[]` | 成员列表 |
| loading | `boolean` | 列表加载中 |
| modalOpen | `boolean` | 弹窗开关 |
| editingMember | `SpaceUserVO \| null` | 正在修改的成员（`null` = 添加） |
| submitting | `boolean` | 提交中 |

## 五、接口调用

| 时机 | 接口 | 参数 |
| --- | --- | --- |
| 进入页面 | `listSpaceUserApi(spaceId)` | 空间 ID |
| 添加成员 | `addSpaceUserApi` | `spaceId`、`userId`、`spaceRole` |
| 修改角色 | `editSpaceUserApi` | `spaceId`、`userId`、`spaceRole` |
| 移除成员 | `deleteSpaceUserApi` | `spaceId`、`userId` |

## 六、交互流程

1. 进入页面：校验 `hasPermission('spaceUser:manage')`，无权限则提示并拦截 → 调 `listSpaceUserApi` 拉取成员列表。
2. 添加成员：点击「添加成员」→ 弹窗输入 `userId` + 选择 `spaceRole` → `addSpaceUserApi` → 刷新列表。
3. 修改角色：行内下拉或弹窗选择新角色 → `editSpaceUserApi` → 刷新。
4. 移除成员：二次确认 → `deleteSpaceUserApi` → 刷新。
5. 角色中文映射：`viewer` 浏览者、`editor` 编辑者、`admin` 管理员。

## 七、权限显隐

- 进入本页需 `spaceUser:manage`（空间 `admin` 或创建者）。
- 创建者（`role === 'creator'`）不可被移除，前端隐藏其「移除」按钮（后端兜底校验）。

## 八、加载 / 空 / 错误态

- 加载中：表格 `loading`。
- 空列表：`Empty`，文案「暂无成员」。
- 无权限：`Result status="403"`。

## 九、关键注意点

1. **添加成员的 `userId` 来源缺口**：后端当前未提供「按账号搜索用户」接口，前端只能让管理员手动输入 `userId`（数字）。若要支持按账号搜索 / 选择用户，需后端补充用户查询接口。
2. 角色为破坏性操作（移除、降级管理员），均需二次确认。
3. 不可移除空间创建者，后端兜底，前端同步隐藏按钮。
