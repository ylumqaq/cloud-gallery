# 空间图片页面设计

> 所属路由：`/space/:spaceId`。本页复用「图片列表」组件，差异仅在 `spaceId` 与权限来源，建议与《图片列表》文档配套阅读。

## 一、页面定位

展示指定空间内的图片，复用图片列表组件；进入空间时同步 `spaceStore` 的当前空间与权限，驱动按钮显隐。

## 二、路由与权限

| 项 | 说明 |
| --- | --- |
| 路由 | `/space/:spaceId`（`spaceId` 为空间 ID） |
| 权限 | 登录 + 空间 `picture:view`（非成员或私有空间无权限） |
| 前置 | 由 `RequireAuth` 包裹 |

## 三、布局与组件树

```
MainLayout
└── SpacePicturePage
    ├── 空间头部（空间名称、返回、成员 / 分析入口）
    └── PictureListPage（复用图片列表，spaceId 来自路由）
```

## 四、页面内状态（useState）

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| space | `SpaceVO \| null` | 空间信息（用于标题） |
| permissionLoaded | `boolean` | 空间权限是否已加载 |

- 图片列表相关状态（`pictureList` / `current` / `searchText` 等）由复用的 `PictureListPage` 内部维护，本页不重复持有。

## 五、接口调用

| 时机 | 接口 | 参数 |
| --- | --- | --- |
| 进入页面 | `getSpaceApi(spaceId)` | 空间信息 |
| 进入页面 | `getMySpacePermissionApi(spaceId)` | 当前用户在空间权限 |
| 列表数据 | `listPictureByPageApi` | 含 `spaceId` 的查询参数 |

- 进入页面时调用 `spaceStore.setCurrentSpace(space)` 与 `spaceStore.fetchSpacePermission(spaceId)`，供 `Permission` / `hasPermission` 读取。

## 六、交互流程

1. 进入页面：读取路由 `:spaceId` → 调 `getSpaceApi` 获取空间标题。
2. 同步空间上下文：`spaceStore.setCurrentSpace(space)` → `fetchSpacePermission(spaceId)`。
3. 权限校验：`hasPermission('picture:view')` 为 `false` → 提示「无权访问该空间」并引导返回。
4. 图片列表复用图片列表文档的交互（搜索 / 分页 / 预览 / 编辑 / 删除）。
5. 空间头部入口：团队空间且拥有 `spaceUser:manage` 时显示「成员管理」；显示「空间分析」入口。

## 七、权限显隐

| 操作 | 权限码 | 说明 |
| --- | --- | --- |
| 查看图片 | `picture:view` | 进入本页的前提 |
| 上传 | `picture:upload` | `editor` / `admin`，显示上传入口 |
| 编辑 | `picture:edit` | `editor` / `admin` |
| 删除 | `picture:delete` | 仅 `admin` |

- 复用《图片列表》权限表；本页差异在于 `currentSpace` 非空，`hasPermission` 走空间权限分支。

## 八、加载 / 空 / 错误态

- 权限加载中：`Spin`。
- 无权限：`Result status="403"` 提示无权访问。
- 空间不存在：后端 `40400`，拦截器提示，页面可引导返回。

## 九、关键注意点

1. 进入空间必须先 `setCurrentSpace`，否则 `hasPermission` 会误判为公共图库权限。
2. 离开空间时清理 `spaceStore.currentSpace`（或由下一个空间覆盖）。
3. 私有空间非创建者无 `picture:view`，应直接拦截，不渲染列表。
