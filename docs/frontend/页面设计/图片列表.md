# 图片列表页面设计

> 所属路由：`/`（公共图库图片列表，登录后首页）。空间图片列表（`/space/:spaceId`）复用本页组件，差异点见「空间场景」小节。
> 配套文档：《前端设计文档》《组件设计文档》《状态管理设计文档》《API 接口文档》。

## 一、页面定位

登录用户的图片浏览入口，以栅格展示图片缩略图，支持关键词搜索、主色调筛选、分页浏览，并提供预览 / 编辑 / 删除操作入口（按空间权限显隐）。

## 二、路由与权限

| 项 | 说明 |
| --- | --- |
| 路由 | `/`（公共图库）；复用场景 `/space/:spaceId` |
| 权限 | 登录即可（公共图库所有登录用户可看）；空间场景需空间 `picture:view` |
| 前置 | 由 `RequireAuth` 包裹，未登录重定向 `/login` |

## 三、布局与组件树

```
MainLayout
└── PictureListPage
    ├── PictureSearchBar          # 关键词 + 颜色搜索
    ├── Row / Col（栅格）
    │   └── PictureCard × N       # 图片卡片（缩略图 + 元信息 + 操作）
    ├── Pagination                # 分页
    └── Empty / Spin              # 空态 / 加载态
```

- 栅格建议用 Ant Design `Row` + `Col`（`xs/sm/md/lg` 响应式），图片卡片宽度自适应；如需瀑布流可引入 `react-masonry`，首版不做。
- 本页替代当前临时的 `HomePage` 作为 `/` 的页面。

## 四、页面内状态（useState）

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| pictureList | `PictureVO[]` | 当前页图片列表 |
| loading | `boolean` | 列表加载中 |
| current | `number` | 当前页码，默认 1 |
| pageSize | `number` | 每页大小，默认 20 |
| total | `number` | 总条数 |
| searchText | `string` | 名称关键词（空 = 不限） |
| picColor | `string` | 主色调（空 = 不限） |

> 图片列表为页面内状态，不入全局 store（见《状态管理设计文档》划分原则）。

## 五、接口调用

| 时机 | 接口 | 参数 |
| --- | --- | --- |
| 进入页面 / 翻页 / 搜索 | `listPictureByPageApi` | `current`、`pageSize`、`spaceId`、`searchText`、`picColor` |
| 删除图片 | `deletePictureApi(id)` | 图片 ID |

- `spaceId` 来源：公共图库不传（`undefined`）；空间场景传 `spaceStore.currentSpace.id`。
- 搜索 / 换页均将 `current` 重置或更新后重新调用列表接口。

## 六、交互流程

1. 进入页面：读取 `spaceStore.currentSpace`（公共图库为 `null`），组装查询参数拉取第 1 页。
2. 搜索：`PictureSearchBar` 回调 `{ searchText, picColor }` → 更新状态并重置 `current = 1` → 重新拉取。
3. 翻页：更新 `current` → 重新拉取。
4. 预览：点击卡片缩略图 → 跳转 `/picture/:id`。
5. 编辑 / 删除：见「权限显隐」，删除需二次确认（`Modal.confirm`），成功后刷新当前页。

## 七、权限显隐

| 操作 | 权限码 | 公共图库 | 空间 |
| --- | --- | --- | --- |
| 预览 / 查看 | `picture:view` | 有（`PUBLIC_PERMISSIONS`） | 按 `spacePermission` |
| 编辑 | `picture:edit` | 无 | 按 `spacePermission` |
| 删除 | `picture:delete` | 无 | 按 `spacePermission` |

- 通过 `Permission` 组件或 `hasPermission(code)` 控制操作按钮显隐（见《组件设计文档》三）。

## 八、加载 / 空 / 错误态

- 加载中：`Spin` 或卡片 `Skeleton`。
- 空列表：`Empty`，文案「暂无图片」。
- 请求失败：错误提示由 `request.ts` 拦截器统一 `message.error`，页面 catch 后不做重复提示。

## 九、关键注意点

1. `spaceId` 语义：公共图库不传（`undefined`），空间传具体 ID；避免与「不限定」混淆。
2. `tags` 后端为 JSON 数组字符串，`PictureCard` 消费 `PictureVO.tags`（前端已解析为 `string[]`），此处无需再转换。
3. 删除为破坏性操作，务必二次确认；删除成功后若当前页仅剩 1 条，回退到上一页。
4. 本页为通用列表组件，空间场景（`/space/:spaceId`）复用，差异仅在 `spaceId` 与权限来源。
