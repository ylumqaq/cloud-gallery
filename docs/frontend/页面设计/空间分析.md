# 空间分析页面设计

> 所属路由：`/space/:spaceId/analyze`。配套《前端设计文档》《组件设计文档》《状态管理设计文档》《API 接口文档》。

## 一、页面定位

对空间（或公共图库）做使用、分类、标签、大小四类分析，以图表可视化展示。

## 二、路由与权限

| 项 | 说明 |
| --- | --- |
| 路由 | `/space/:spaceId/analyze` |
| 权限 | 登录 + 空间 `picture:view`（空间成员）；公共图库所有登录用户可看 |
| 前置 | 由 `RequireAuth` 包裹 |

## 三、布局与组件树

```
MainLayout
└── SpaceAnalyzePage
    ├── 空间头部（返回）
    ├── UsageAnalyzeCard         # 使用率进度 / 仪表盘
    ├── CategoryAnalyzeChart     # 分类统计图
    ├── TagAnalyzeChart          # 标签统计图
    └── SizeAnalyzeChart         # 大小区间分布图
```

- 图表组件详见《组件设计文档》五，统一通过 `AnalyzeChart` 封装 ECharts 实例生命周期。

## 四、页面内状态（useState）

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| usage | `SpaceUsageAnalyzeVO \| null` | 使用分析 |
| categoryList | `SpaceCategoryAnalyzeVO[]` | 分类分析 |
| tagList | `SpaceTagAnalyzeVO[]` | 标签分析 |
| sizeList | `SpaceSizeAnalyzeVO[]` | 大小分析 |
| loading | `boolean` | 加载中 |

## 五、接口调用

| 时机 | 接口 | 参数 |
| --- | --- | --- |
| 进入页面 | `getUsageAnalyzeApi` | `spaceId` |
| 进入页面 | `getCategoryAnalyzeApi` | `spaceId` |
| 进入页面 | `getTagAnalyzeApi` | `spaceId` |
| 进入页面 | `getSizeAnalyzeApi` | `spaceId` |

- 四个接口可并行请求（`Promise.all`）；`spaceId` 为空表示统计公共图库。

## 六、交互流程

1. 进入页面：读取 `:spaceId`，并行拉取四类分析数据。
2. `UsageAnalyzeCard` 消费 `usage`，展示已用数量 / 总大小、上限与使用率（`countUsageRatio` / `sizeUsageRatio`，百分比 0-100）。
3. `CategoryAnalyzeChart` / `TagAnalyzeChart` 消费列表数据，展示 `count` 与 `totalSize`。
4. `SizeAnalyzeChart` 按固定区间（`<100KB` / `100KB-500KB` / `500KB-1MB` / `>1MB` / `未知`）展示分布。

## 七、权限显隐

- 本页仅空间成员（`picture:view`）可访问；公共图库所有登录用户可看。
- 空间用量排行（`rank`）接口仅系统管理员，归属「管理后台」页面（子批 3），不在此页展示。

## 八、加载 / 空 / 错误态

- 加载中：`Spin` 或图表骨架。
- 无数据：图表显示空态（ECharts 空数据或 `Empty`）。
- 请求失败：拦截器统一提示。

## 九、关键注意点

1. `countUsageRatio` / `sizeUsageRatio` 为百分比（0-100），进度条 / 仪表盘直接使用。
2. `sizeRange` 区间文案由后端固定返回，前端直接展示，无需自行计算。
3. 分类 / 标签统计含 `totalSize`（字节），图表展示时统一格式化。
4. 分析接口 `spaceId` 为空 = 公共图库；公共图库分析可复用本页组件（`spaceId` 缺省）。
