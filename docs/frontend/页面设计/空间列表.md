# 空间列表页面设计

> 所属路由：`/space/manage`（我的空间列表）。配套《前端设计文档》《组件设计文档》《状态管理设计文档》《API 接口文档》。

## 一、页面定位

管理当前登录用户创建的空间（私有 / 团队），支持创建、编辑、删除空间，并提供进入空间、成员管理、空间分析的入口。

## 二、路由与权限

| 项 | 说明 |
| --- | --- |
| 路由 | `/space/manage` |
| 权限 | 登录即可 |
| 前置 | 由 `RequireAuth` 包裹 |

## 三、布局与组件树

```
MainLayout
└── SpaceManagePage
    ├── 顶部操作区（「创建空间」按钮）
    ├── Row / Col
    │   └── 空间卡片 × N（Card：名称、类型标识、创建时间、操作按钮）
    └── SpaceFormModal（创建 / 编辑弹窗）
```

- 空间卡片用 Ant Design `Card` 内联渲染即可（如后续多处复用可封装为 `SpaceCard`，当前不强制）。
- 空间类型标识：私有 / 团队 中文标签。

## 四、页面内状态（useState）

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| spaceList | `SpaceVO[]` | 我的空间列表 |
| loading | `boolean` | 列表加载中 |
| modalOpen | `boolean` | 创建 / 编辑弹窗开关 |
| editingSpace | `SpaceVO \| null` | 正在编辑的空间（`null` = 创建） |
| submitting | `boolean` | 提交中 |

## 五、接口调用

| 时机 | 接口 | 参数 |
| --- | --- | --- |
| 进入页面 | `listMySpaceApi()` | 无 |
| 创建空间 | `addSpaceApi` | `spaceName`、`spaceType`（返回新空间 ID） |
| 编辑空间 | `editSpaceApi` | `id`、`spaceName` |
| 删除空间 | `deleteSpaceApi(id)` | 空间 ID |

## 六、交互流程

1. 进入页面：调 `listMySpaceApi` 拉取我的空间列表。
2. 创建：点击「创建空间」→ 弹窗输入 `spaceName`、选择 `spaceType`（0 私有 / 1 团队）→ `addSpaceApi` → 成功后刷新列表。
3. 编辑：点击卡片「编辑」→ 弹窗修改 `spaceName` → `editSpaceApi` → 刷新。
4. 删除：二次确认（`Modal.confirm`）→ `deleteSpaceApi` → 刷新。
5. 进入空间：点击卡片 → 跳转 `/space/:spaceId`（空间图片）。
6. 团队空间卡片提供「成员管理」（`/space/:spaceId/members`）、「空间分析」（`/space/:spaceId/analyze`）入口；私有空间仅提供进入空间。

## 七、权限显隐

- 本页为「我的空间」，所有登录用户可见，创建 / 编辑 / 删除无需空间权限（后端校验创建者或管理员）。
- 删除 / 编辑按钮仅对本人创建的空间展示（后端兜底校验，前端可按 `space.userId === 当前用户 id` 隐藏）。

## 八、加载 / 空 / 错误态

- 加载中：`Spin` 或卡片 `Skeleton`。
- 空列表：`Empty`，文案「暂无空间，点击创建」。
- 请求失败：拦截器统一提示。

## 九、关键注意点

1. 空间类型中文映射：`0` → 私有、`1` → 团队。
2. 删除为破坏性操作，二次确认；团队空间删除会连带成员关系与图片，后端兜底校验。
3. 创建成功后获得新空间 ID，可直接引导用户进入该空间或刷新列表。
