# 云图库前端状态管理设计文档

> 本文档为 `frontend/src/stores/` 的详细设计，是《前端设计文档》的补充，配套《组件设计文档》《API 接口文档》阅读。
> 状态管理采用 Zustand 5，遵循「跨页面共享的状态才入 store，页面内状态用 useState / useReducer」的原则。

## 一、Store 总览

### 1.1 划分原则

| 状态 | 存放位置 | 说明 |
| --- | --- | --- |
| 登录态（token / 当前用户） | `userStore` | 全局唯一，跨所有页面 |
| 当前空间 / 空间权限 | `spaceStore` | 图片列表、成员、分析等多页面共享 |
| 图片列表分页、搜索结果、详情 | 页面内 `useState` | 各页面独立，不跨页共享，不入全局 store |

### 1.2 Store 清单

| Store | 文件 | 状态 | 持久化 |
| --- | --- | --- | --- |
| userStore | `stores/user.ts` | token、loginUser | token 持久化 localStorage |
| spaceStore | `stores/space.ts` | currentSpace、spaceList、spacePermission | 无（规划） |

## 二、userStore（已落地）

### 2.1 状态字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| token | `string` | 登录凭证（Sa-Token），初始化时从 localStorage 恢复 |
| loginUser | `UserVO \| null` | 当前登录用户脱敏信息 |

### 2.2 动作

| 动作 | 说明 | 调用接口 |
| --- | --- | --- |
| login(account, password) | 登录，保存 token 与用户信息 | `POST /api/user/login` |
| fetchLoginUser() | 拉取当前登录用户（刷新 / 初始化） | `GET /api/user/get/login` |
| logout() | 退出并清理本地状态 | `POST /api/user/logout` |
| reset() | 清理状态（未登录跳转时使用） | 无 |

### 2.3 持久化

- token 通过 `utils/token.ts`（`getToken` / `setToken` / `clearToken`）读写 localStorage。
- `loginUser` 不持久化，刷新后由 `fetchLoginUser` 重新拉取。

### 2.4 目标实现

```ts
import { create } from 'zustand'
import type { UserVO } from '../types/user'
import { getLoginUserApi, loginApi, logoutApi } from '../api/user'
import { clearToken, getToken, setToken } from '../utils/token'

interface UserState {
  token: string
  loginUser: UserVO | null
  login: (userAccount: string, userPassword: string) => Promise<void>
  fetchLoginUser: () => Promise<void>
  logout: () => Promise<void>
  reset: () => void
}

export const useUserStore = create<UserState>()((set) => ({
  token: getToken(), // 初始化时从 localStorage 恢复
  loginUser: null,

  // 登录：拆出 token 与脱敏信息，loginUser 仅存脱敏信息
  async login(userAccount, userPassword) {
    const res = await loginApi({ userAccount, userPassword }) // LoginUserVO（含 token）
    const { token, ...user } = res // 分离 token 与 UserVO
    setToken(token)
    set({ token, loginUser: user })
  },

  // 拉取当前登录用户脱敏信息
  async fetchLoginUser() {
    const user = await getLoginUserApi() // UserVO
    set({ loginUser: user })
  },

  // 退出：调用接口并清理本地状态
  async logout() {
    try {
      await logoutApi()
    } finally {
      clearToken()
      set({ token: '', loginUser: null })
    }
  },

  // 重置登录态
  reset() {
    clearToken()
    set({ token: '', loginUser: null })
  },
}))
```

## 三、spaceStore（规划）

### 3.1 状态字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| currentSpace | `SpaceVO \| null` | 当前选中空间；`null` 表示公共图库 |
| spaceList | `SpaceVO[]` | 我的空间列表（供空间切换） |
| spacePermission | `SpaceUserPermissionVO \| null` | 当前用户在 `currentSpace` 的权限；公共图库为 `null` |

### 3.2 动作

| 动作 | 说明 | 调用接口 |
| --- | --- | --- |
| setCurrentSpace(space) | 设置当前空间（空 = 公共图库） | 无 |
| fetchMySpaces() | 拉取我的空间列表 | `GET /api/space/list` |
| fetchSpacePermission(spaceId) | 拉取当前用户在某空间的权限 | `GET /api/spaceUser/get?spaceId=xxx` |
| reset() | 清空空间相关状态 | 无 |

### 3.3 权限判定逻辑

- 公共图库（`currentSpace === null`）：使用后端配置的公共权限 `picture:view` + `picture:upload`（对应 `PUBLIC_PERMISSIONS`）。
- 团队空间：以 `spacePermission.permissions` 为准。
- 私有空间非创建者：后端返回 `role = null`、`permissions` 为空，此时无任何空间权限。

### 3.4 目标实现

```ts
import { create } from 'zustand'
import type { SpaceVO } from '../types/space'
import type { SpaceUserPermissionVO } from '../types/spaceUser'
import { listMySpaceApi } from '../api/space'
import { getMySpacePermissionApi } from '../api/spaceUser'

interface SpaceState {
  currentSpace: SpaceVO | null
  spaceList: SpaceVO[]
  spacePermission: SpaceUserPermissionVO | null
  setCurrentSpace: (space: SpaceVO | null) => void
  fetchMySpaces: () => Promise<void>
  fetchSpacePermission: (spaceId: number) => Promise<void>
  reset: () => void
}

export const useSpaceStore = create<SpaceState>()((set) => ({
  currentSpace: null, // null = 公共图库
  spaceList: [],
  spacePermission: null,

  // 设置当前空间：切换空间时同步清空旧权限，由页面重新拉取
  setCurrentSpace(space) {
    set({ currentSpace: space, spacePermission: null })
  },

  // 拉取我的空间列表
  async fetchMySpaces() {
    const list = await listMySpaceApi()
    set({ spaceList: list })
  },

  // 拉取当前用户在某空间的权限（进入空间页面时调用）
  async fetchSpacePermission(spaceId) {
    const permission = await getMySpacePermissionApi(spaceId)
    set({ spacePermission: permission })
  },

  reset() {
    set({ currentSpace: null, spaceList: [], spacePermission: null })
  },
}))
```

## 四、权限辅助函数 hasPermission

> 完整设计见《组件设计文档》3.2，这里补充与 `spaceStore` 的关系。

```ts
// src/utils/permission.ts
import { useSpaceStore } from '../stores/space'
import { PUBLIC_PERMISSIONS, type PermissionCode } from '../constants/permission'

// 判断当前用户在「当前空间 / 公共图库」下是否拥有指定权限码
export function hasPermission(code: PermissionCode): boolean {
  const { currentSpace, spacePermission } = useSpaceStore.getState()
  if (!currentSpace) {
    return PUBLIC_PERMISSIONS.includes(code) // 公共图库
  }
  return spacePermission?.permissions?.includes(code) ?? false
}
```
