# 云图库前端组件设计文档

> 本文档为 `frontend/src/components/`、`frontend/src/layouts/` 的组件详细设计，是《前端设计文档》的补充，配套《状态管理设计文档》《API 接口文档》阅读。
> 组件统一基于 React 19 函数组件 + TypeScript + Ant Design 6，遵循「视图与逻辑分离」：业务数据获取与状态读写收敛到 store / 自定义 Hook，组件只负责渲染与交互。

## 二、布局组件

### 2.1 MainLayout（后台主布局）

- 文件：`src/layouts/MainLayout.tsx`
- 职责：提供后台统一框架，左侧导航菜单、顶部用户信息与退出入口、右侧内容区。
- 依赖：
  - `useUserStore`（`loginUser`、`logout`）
  - `react-router-dom`（导航跳转）
  - `constants/permission.ts` 的 `SYSTEM_ROLE`（管理员菜单显隐）

**Props**

```ts
interface MainLayoutProps {
  children: ReactNode // 内容区（由路由 Outlet 渲染）
}
```

**内部结构**

- Ant Design `Layout`（Sider + Header + Content）。
- Sider 菜单项由 `SYSTEM_ROLE` 控制显隐：普通菜单（图片列表、上传、以图搜图）所有登录用户可见；系统菜单（空间用量排行、用户角色管理）仅 `admin` / `super_admin` 可见。
- Header 展示 `loginUser` 昵称与头像，提供「退出登录」下拉，触发 `logout` 后跳转 `/login`。
- 菜单项配置收敛到一个常量数组（含 `path` / `label` / `requiredRole`），由布局统一渲染，避免散落各页面。

## 三、权限组件

> 权限分两层：系统角色（路由级，见 `RequireAuth` 与路由 meta）与空间权限码（按钮级，见本节）。本节只负责按钮级空间权限。

### 3.1 公共权限常量（前置约定）

在 `constants/permission.ts` 补充公共图库的默认权限（与后端 `spaceUserAuthConfig.json` 的 `publicPermissions` 一致）：

```ts
// 公共图库默认权限：登录用户可查看与上传
export const PUBLIC_PERMISSIONS: PermissionCode[] = [
  PERMISSION.PICTURE_VIEW,
  PERMISSION.PICTURE_UPLOAD,
]
```

### 3.2 hasPermission 工具函数

- 文件：`src/utils/permission.ts`
- 职责：判断当前用户是否拥有指定空间权限码，公共图库回退到公共权限。
- 依赖：`spaceStore`、`PUBLIC_PERMISSIONS`、`PermissionCode`。

```ts
import { useSpaceStore } from '../stores/space'
import { PUBLIC_PERMISSIONS, type PermissionCode } from '../constants/permission'

// 判断当前用户在「当前空间 / 公共图库」下是否拥有指定权限码
export function hasPermission(code: PermissionCode): boolean {
  const { currentSpace, spacePermission } = useSpaceStore.getState()
  // 公共图库：使用后端配置的公共权限
  if (!currentSpace) {
    return PUBLIC_PERMISSIONS.includes(code)
  }
  return spacePermission?.permissions?.includes(code) ?? false
}
```

> 说明：`hasPermission` 同时作为 `Permission` 组件的内部实现，页面逻辑判断直接复用。

### 3.3 Permission 组件

- 文件：`src/components/Permission.tsx`
- 职责：有权限则渲染 `children`，无权限渲染 `fallback`（默认不渲染）。

**Props**

```ts
interface PermissionProps {
  code: PermissionCode // 所需权限码
  fallback?: ReactNode // 无权限时的替代内容，默认 null
  children: ReactNode // 有权限时渲染的内容
}
```

**实现**

```tsx
import type { ReactNode } from 'react'
import { hasPermission } from '../utils/permission'
import type { PermissionCode } from '../constants/permission'

interface PermissionProps {
  code: PermissionCode
  fallback?: ReactNode
  children: ReactNode
}

// 按钮级权限组件：无权限时不渲染 children（可自定义 fallback）
export default function Permission({ code, fallback = null, children }: PermissionProps) {
  return <>{hasPermission(code) ? children : fallback}</>
}
```

**使用示例**

```tsx
<Permission code={PERMISSION.PICTURE_DELETE}>
  <Button danger onClick={() => onDelete(picture)}>删除</Button>
</Permission>
```

## 四、图片业务组件

### 4.1 PictureCard（图片卡片）

- 文件：`src/components/PictureCard.tsx`
- 职责：展示单张图片缩略图与元信息（名称、分类、标签、大小、主色调），并提供预览 / 编辑 / 删除操作入口。
- 依赖：`types/picture.ts` 的 `PictureVO`；Ant Design `Card` / `Image` / `Tag` / `Typography`。

**Props**

```ts
interface PictureCardProps {
  picture: PictureVO // 图片数据（tags 已解析为 string[]）
  showActions?: boolean // 是否展示操作按钮，默认 false
  onPreview?: (picture: PictureVO) => void
  onEdit?: (picture: PictureVO) => void
  onDelete?: (picture: PictureVO) => void
}
```

**关键约定**

- 缩略图优先用 `picture.thumbnailUrl`，为空时回退 `picture.url`；点击触发 `onPreview`（用 Ant Design `Image` 预览组实现）。
- `picSize`（字节）统一格式化为 `KB` / `MB` 展示。
- `tags`（`string[]`）用 `Tag` 展示，超过 N 个折叠；`picColor` 以主色调色块展示。
- 编辑 / 删除按钮由调用方通过 `Permission` 组件或 `showActions` 控制，`PictureCard` 本身不做权限判断，保持纯粹。

### 4.2 PictureUploader（图片上传器）

- 文件：`src/components/PictureUploader.tsx`
- 职责：支持「本地文件」与「网络 URL」两种上传方式；本地文件做类型 / 大小预校验；构造 `FormData` 调用 `uploadPictureApi`。
- 依赖：`api/picture.ts` 的 `uploadPictureApi`；Ant Design `Upload` / `Form` / `Input` / `Button`。

**Props**

```ts
interface PictureUploaderProps {
  spaceId?: number // 目标空间，空 = 公共图库
  onSuccess?: (picture: PictureVO) => void // 上传成功回调
}
```

**关键约定**

- 本地文件：`Upload` 组件 `beforeUpload` 中校验，仅允许 `jpeg/png/jpg/webp`，大小 ≤ 2MB，校验失败 `message` 提示并阻止上传。
- URL 上传：`Input` 输入图片 URL，提交时以 `fileUrl` 参数封装进 `FormData`。
- 公共参数随 `FormData` 携带：`spaceId`、`picName`、`category`、`tags`（JSON 数组字符串）。
- 上传成功后回调 `onSuccess(picture)` 供父组件刷新列表 / 关闭弹窗。

### 4.3 PictureSearchBar（图片搜索栏）

- 文件：`src/components/PictureSearchBar.tsx`
- 职责：提供关键词 + 主色调搜索条件输入，回调父组件触发查询。
- 依赖：Ant Design `Input` / `Space` / `ColorPicker` / `Button`。

**Props**

```ts
interface PictureSearchBarProps {
  onSearch?: (params: { searchText?: string; picColor?: string }) => void
}
```

**关键约定**

- `picColor` 由 `ColorPicker` 选择后转十六进制字符串（如 `0xff0000`），与后端「按颜色搜索」参数格式一致。
- 点击「搜索」时回调整合后的查询条件，父组件负责拼装分页参数并调用接口。

## 六、编码约定

1. **组件纯渲染**：业务数据获取、状态读写收敛到 store / 自定义 Hook，组件 props 明确、少副作用。
2. **权限统一走 `Permission` / `hasPermission`**，组件内部不做硬编码角色判断。
3. **类型来自 `types/`**：组件 props 引用的 VO 类型必须与后端 VO 字段一致（以《API 接口文档》为准）。
4. **命名**：组件文件用 PascalCase，props 接口用 `XxxProps`；回调统一 `onXxx` 命名。
5. **ECharts 组件**统一通过 `AnalyzeChart` 封装实例生命周期，避免重复初始化 / 销毁逻辑。
