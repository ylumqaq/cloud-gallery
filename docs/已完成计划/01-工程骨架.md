### 4. 统一返回与统一异常（common 包）

| 文件 | 职责 |
| --- | --- |
| `common/BaseResponse.java` | 统一返回对象 `code` / `data` / `message` |
| `common/ResultUtils.java` | 静态工厂方法 `success` / `error` 系列 |
| `common/ErrorCode.java` | 错误码枚举（0 / 40000 / 40100 / 40101 / 40300 / 40400 / 50000 / 50001） |
| `common/BusinessException.java` | 业务异常（携带 code + message） |
| `common/GlobalExceptionHandler.java` | `@RestControllerAdvice` 统一捕获并转 `BaseResponse` |

`GlobalExceptionHandler` 处理规则：

- `BusinessException` → 业务 code + message。
- 参数校验异常 `MethodArgumentNotValidException` → 取首条校验信息，code=40000。
- Sa-Token `NotLoginException` → 40100；`NotPermissionException` / `NotRoleException` → 40101（该部分于阶段 2 引入 Sa-Token 后补充）。
- 兜底 `Exception` → 50000。
