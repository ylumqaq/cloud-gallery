# 云图库实施计划文档

## 一、开发顺序总览

按依赖关系，推荐的开发顺序：

```
工程骨架 → 用户认证 → 空间与成员权限 → 图片上传 → 以图搜图 → 分库分表 → 空间分析与其他
```

| 阶段 | 内容 | 依赖 |
| --- | --- | --- |
| 1. 工程骨架 | 工程初始化、统一返回/异常、数据库建表 | 无 |
| 2. 用户认证 | 注册 / 登录 / 脱敏 | 阶段 1 |
| 3. 空间与成员权限 | 空间 CRUD + RBAC 权限 | 阶段 2 |
| 4. 图片上传 | 上传 / 查询 / 编辑 / 删除 / 批量抓取 | 阶段 3 |
| 5. 以图搜图 | 向量提取 + pgvector 检索 | 阶段 4 |
| 6. 分库分表 | ShardingSphere 分片 | 阶段 4 |
| 7. 空间分析与其他 | 统计分析 / 颜色搜索 / 多级缓存 | 阶段 4 |

## 二、各阶段任务拆分

### 阶段 1：工程骨架

- [ ] 创建 Spring Boot 3.5.16 工程，引入 Maven 依赖（见《环境部署文档》）
- [ ] 配置 `application.yml`（数据源、Redis、COS、Sa-Token、分片）
- [ ] 统一返回 `BaseResponse` + `ResultUtils`
- [ ] 统一异常 `GlobalExceptionHandler` + `BusinessException` + 错误码
- [ ] 初始化 MySQL 表（user / space / space_user / picture）
- [ ] 初始化 PostgreSQL 的 pgvector 与 `picture_embedding` 表

### 阶段 2：用户认证

- [ ] user 表实体 / Mapper / Service
- [ ] 注册接口
- [ ] 登录接口（`StpUtil.login` + Redis 会话）
- [ ] 获取当前登录用户、退出登录
- [ ] 用户信息脱敏

### 阶段 3：空间与成员权限

- [ ] space 表 CRUD（创建 / 编辑 / 删除 / 详情 / 列表）
- [ ] space_user 成员管理（添加 / 改角色 / 移除 / 列表）
- [ ] 权限配置 `spaceUserAuthConfig.json`
- [ ] 空间权限体系：`SpaceUserAuthAspect` + `SpaceUserAuthManager` + `@SaSpaceCheckPermission`

### 阶段 4：图片上传

- [ ] picture 表实体 / Mapper / Service
- [ ] 上传模板 `PictureUploadTemplate` + `FilePictureUpload` / `UrlPictureUpload`
- [ ] `CosManager`（COS 上传 + CI 图片处理）
- [ ] 分页查询 / 详情 / 编辑 / 删除
- [ ] 批量抓取上传（Jsoup）

### 阶段 5：以图搜图

- [ ] CI 图片向量特征提取集成
- [ ] 向量写入 PostgreSQL `picture_embedding`
- [ ] 以图搜图接口（pgvector 检索 `picture_id` → MySQL 回查详情）
- [ ] 删除图片时双删向量

### 阶段 6：分库分表

- [ ] ShardingSphere 分片规则配置
- [ ] `PictureShardingAlgorithm` 自定义分片算法
- [ ] `DynamicShardingManager` 动态建表 + 规则刷新
- [ ] 按 `space_id` 路由联调验证

### 阶段 7：空间分析与其他

- [x] 空间分析接口（使用 / 分类 / 标签 / 大小 / 排行）
- [x] 按颜色搜索（主色调 + RGB 欧氏距离）
- [x] 多级缓存（Caffeine + Redis）

## 三、里程碑

| 里程碑 | 达成标准 |
| --- | --- |
| M1 可运行 | 工程能启动，统一返回/异常生效，数据库表建好 |
| M2 可登录 | 注册/登录/退出可用，登录态存 Redis |
| M3 有权限 | 空间 + 成员 + RBAC 鉴权可用 |
| M4 能上传 | 图片上传/查询/编辑/删除可用，COS/CI 打通 |
| M5 能搜图 | 以图搜图可用 |
| M6 可分表 | 分片路由可用 |
| M7 完整 | 分析、颜色搜索、缓存等功能补齐 |
