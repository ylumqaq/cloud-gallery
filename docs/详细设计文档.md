# 云图库详细设计文档

## 一、用户认证流程

### 1. 登录流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant Ctrl as UserController
    participant S as UserServiceImpl
    participant DB as MySQL
    participant R as Redis

    C->>Ctrl: POST /api/user/login (账号, 密码)
    Ctrl->>S: 调用登录
    S->>DB: 按账号查询用户
    DB-->>S: 用户记录
    S->>S: 校验密码（加密比对）
    S->>S: StpUtil.login(userId)
    S->>R: 写入登录会话（Spring Session）
    S-->>Ctrl: 脱敏用户信息 + token
    Ctrl-->>C: BaseResponse
```

说明：登录态存 Redis，由 Spring Session 托管，实现分布式会话。

### 2. 注册流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as UserServiceImpl
    participant DB as MySQL

    C->>S: 注册（账号, 密码, 确认密码）
    S->>S: 校验参数 + 账号唯一性
    S->>S: 密码加密
    S->>DB: 插入 user 表
    DB-->>S: userId
    S-->>C: 注册成功
```

## 二、空间权限鉴权流程（核心）

```mermaid
sequenceDiagram
    participant C as 客户端
    participant A as SpaceUserAuthAspect
    participant M as SpaceUserAuthManager
    participant DB as MySQL

    C->>A: 请求（带 token + spaceId）
    A->>A: 命中 @SaSpaceCheckPermission(picture:upload)
    A->>A: userId = StpUtil.getLoginIdAsLong()
    A->>A: spaceId = resolveSpaceId(方法参数/请求参数)
    A->>M: getPermissionList(spaceId, userId)
    M->>DB: 查空间类型 / 查 space_user 角色
    DB-->>M: 角色（viewer/editor/admin）
    M->>M: 角色映射权限码列表
    M-->>A: 返回权限码列表
    A->>A: 判断是否包含 picture:upload
    alt 包含
        A-->>C: 放行
    else 不包含
        A-->>C: 拒绝（无权限）
    end
```

说明：权限「配置化 + 注解化 + 切面化」，公共/私有/团队三种场景在 `SpaceUserAuthManager.getPermissionList` 里分支收敛。

## 三、图片上传流程（核心）

### 1. 模板方法执行流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant Ctrl as PictureController
    participant S as PictureServiceImpl
    participant T as PictureUploadTemplate
    participant COS as CosManager(COS+CI)
    participant DB as MySQL
    participant PG as PostgreSQL

    C->>Ctrl: POST /api/picture/upload (file 或 fileUrl)
    Ctrl->>S: uploadPicture(inputSource, ...)
    S->>S: 按 inputSource 选择模板（File/Url）
    S->>T: 执行模板方法
    T->>T: validPicture() 校验
    T->>T: processFile() 获取/处理文件
    T->>COS: putPictureObject() 上传 COS
    COS-->>T: 图片信息（宽高/格式/主色调）+ CI 处理 + 向量
    T->>DB: 插入 picture 表
    T->>PG: 写入 picture_embedding 向量
    T-->>S: UploadPictureResult
    S-->>C: BaseResponse
```

### 2. 关键步骤

1. `validPicture()`：文件大小 ≤ 2MB、格式校验（jpeg/png/jpg/webp）。
2. `processFile()`：本地文件转存临时文件，或 URL 下载到本地。
3. `CosManager.putPictureObject()`：上传 COS + CI 完成 webp 压缩、缩略图、宽高/主色调提取、向量特征提取。
4. 双写：MySQL `picture` 存元数据，PostgreSQL `picture_embedding` 存向量。MySQL 写入走本地事务，PG 与 COS 采用最终一致（补偿 + 对账），详见《事务设计文档》。

## 四、以图搜图流程（核心）

```mermaid
sequenceDiagram
    participant C as 客户端
    participant Ctrl as PictureController
    participant CI as 数据万象 CI
    participant PG as PostgreSQL(pgvector)
    participant DB as MySQL

    C->>Ctrl: POST /api/picture/search/by/picture (查询图)
    Ctrl->>CI: 图片向量特征提取
    CI-->>Ctrl: 查询向量
    Ctrl->>PG: 检索相似 picture_id（embedding <=> 向量）
    PG-->>Ctrl: 相似 picture_id 列表（topK）
    Ctrl->>DB: 按 id 列表查图片详情
    DB-->>Ctrl: 图片列表
    Ctrl-->>C: BaseResponse
```

说明：向量检索只返回 `picture_id`，图片详情以 MySQL 为准，两库职责清晰。

## 五、分表路由流程

```mermaid
sequenceDiagram
    participant S as 业务 SQL
    participant SS as ShardingSphere
    participant A as PictureShardingAlgorithm
    participant DB as MySQL

    S->>SS: SQL（携带 spaceId）
    SS->>A: doSharding(spaceId)
    alt spaceId 为空
        A-->>SS: 路由到 picture（公共图库）
    else spaceId 非空
        A-->>SS: 路由到 picture_{spaceId}
    end
    SS->>DB: 执行 SQL
```

说明：按 `space_id` 分表，团队空间图片落到 `picture_{spaceId}`。

## 六、关键类职责汇总

| 类 | 职责 |
| --- | --- |
| `UserServiceImpl` | 注册 / 登录 / 脱敏 |
| `PictureServiceImpl` | 图片上传 / 搜索 / 批量抓取 / 以图搜图 / 按颜色搜索 |
| `SpaceServiceImpl` | 空间创建 / 编辑 / 删除 |
| `SpaceAnalyzeServiceImpl` | 空间使用 / 分类 / 标签 / 大小 / 排行统计 |
| `SpaceUserAuthManager` | 空间成员与权限管理 |
| `SpaceUserAuthAspect` | 拦截 `@SaSpaceCheckPermission` 完成空间权限校验 |
| `PictureUploadTemplate` | 上传流程模板方法 |
| `FilePictureUpload` / `UrlPictureUpload` | 本地 / URL 上传子类 |
| `CosManager` | COS 存储 + CI 图片处理封装 |
| `ColorSimilarUtils` | 主色调 hex 转 RGB 与 RGB 欧氏距离计算 |
| `PictureShardingAlgorithm` | 自定义分片算法 |
| `DynamicShardingManager` | 动态建表 + 分片规则刷新 |
| `TwoLevelCacheManager` / `TwoLevelCache` | Caffeine + Redis 两级缓存 |
| `GlobalExceptionHandler` | 统一异常处理 |
| `BaseResponse` / `ResultUtils` | 统一返回 |
