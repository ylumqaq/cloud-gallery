# 阶段 3：空间与成员权限 —— 接口测试

> 本手册用于阶段 3 的手动接口测试与回归验证，配套自动化测试见文末「七、自动化测试」。
> 所有接口均以 `/api` 为上下文路径，登录态通过请求头 `satoken` 传递 token。

## 一、测试范围与约定

- 范围：空间 CRUD、空间成员管理、空间权限鉴权（viewer / editor / admin）。
- 统一返回结构：

```json
{ "code": 0, "data": null, "message": "ok" }
```

- 错误码约定：

| 错误码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录 |
| 40101 | 无权限 |
| 40300 | 禁止访问 |
| 40400 | 请求数据不存在 |
| 50000 | 系统内部异常 |

## 二、测试环境准备

1. 启动 MySQL（库名 `cloud_gallery`，含 `space` / `space_user` 表）。
2. 启动 Redis（端口 6379）。
3. 启动服务：端口 8123，上下文路径 `/api`。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.19.10-hotspot'
mvn spring-boot:run
```

## 三、登录态获取（前置）

注册并登录，从登录响应 `data.token` 中取出 token，后续请求放入请求头 `satoken`。

```powershell
$base = "http://localhost:8123/api"

# 1. 注册
Invoke-RestMethod -Uri "$base/user/register" -Method Post -ContentType "application/json" `
  -Body '{"userAccount":"tester1","userPassword":"12345678","checkPassword":"12345678"}'

# 2. 登录，获取 token
$login = Invoke-RestMethod -Uri "$base/user/login" -Method Post -ContentType "application/json" `
  -Body '{"userAccount":"tester1","userPassword":"12345678"}'
$token = $login.data.token
```

带 token 的请求示例：

```powershell
Invoke-RestMethod -Uri "$base/space/list" -Method Get -Headers @{ satoken = $token }
```

## 四、空间模块测试用例

### 1. 创建空间

`POST /api/space/add`，权限：登录。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| spaceName | string | 空间名称（非空，≤128） |
| spaceType | int | 0 私有 / 1 团队 |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SPACE-001 | 创建私有空间 | spaceType=0 | code=0，返回 spaceId |
| TC-SPACE-002 | 创建团队空间 | spaceType=1 | code=0，返回 spaceId |
| TC-SPACE-003 | 类型非法 | spaceType=99 | code=40000 |
| TC-SPACE-004 | 名称为空 | spaceName 缺省 | code=40000 |
| TC-SPACE-005 | 未登录 | 不带 token | code=40100 |

### 2. 编辑空间

`POST /api/space/edit`，权限：登录（创建者或管理员）。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | long | 空间 ID |
| spaceName | string | 新名称 |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SPACE-006 | 创建者编辑 | 本人修改名称 | code=0 |
| TC-SPACE-007 | 非创建者编辑 | 他人修改名称 | code=40101 |

### 3. 删除空间

`POST /api/space/delete`，权限：登录（创建者或管理员）。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | long | 空间 ID |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SPACE-008 | 创建者删除 | 本人删除 | code=0，同时清理成员关系 |
| TC-SPACE-009 | 非创建者删除 | 他人删除 | code=40101 |

### 4. 空间详情

`GET /api/space/get/{id}`，权限：登录。

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SPACE-010 | 查询详情 | 传入空间 ID | code=0，返回 id/spaceName/spaceType/userId/createTime |
| TC-SPACE-011 | 空间不存在 | 传入不存在的 ID | code=40400 |

### 5. 我的空间列表

`GET /api/space/list`，权限：登录。

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SPACE-012 | 查询列表 | 登录后调用 | code=0，仅返回当前用户创建的空间 |

## 五、空间成员模块测试用例

### 1. 添加成员

`POST /api/spaceUser/add`，权限：登录 + `@SaSpaceCheckPermission(spaceUser:manage)`。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| spaceId | long | 空间 ID |
| userId | long | 被添加用户 ID |
| spaceRole | string | viewer / editor / admin |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-MEMBER-001 | 创建者添加成员 | 团队空间，admin 添加 viewer | code=0，返回成员关系 ID |
| TC-MEMBER-002 | 角色非法 | spaceRole=boss | code=40000 |
| TC-MEMBER-003 | 重复添加 | 同一用户再添加 | code=40000 |
| TC-MEMBER-004 | 添加创建者本人 | userId=创建者 | code=40000 |
| TC-MEMBER-005 | 被添加用户不存在 | userId 无效 | code=40400 |

### 2. 修改成员角色

`POST /api/spaceUser/edit`，权限：登录 + `spaceUser:manage`。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| spaceId | long | 空间 ID |
| userId | long | 成员用户 ID |
| spaceRole | string | 新角色 |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-MEMBER-006 | 修改角色 | viewer → editor | code=0 |
| TC-MEMBER-007 | 非成员改角色 | 用户不是成员 | code=40400 |
| TC-MEMBER-008 | 角色非法 | 新角色非法 | code=40000 |

### 3. 移除成员

`POST /api/spaceUser/delete`，权限：登录 + `spaceUser:manage`。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| spaceId | long | 空间 ID |
| userId | long | 成员用户 ID |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-MEMBER-009 | 移除成员 | admin 移除成员 | code=0 |
| TC-MEMBER-010 | 移除不存在成员 | 用户不是成员 | code=40400 |

### 4. 成员列表

`GET /api/spaceUser/list?spaceId=xx`，权限：登录 + `picture:view`。

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-MEMBER-011 | 查询成员 | 传入 spaceId | code=0，返回成员列表（含昵称/账号/头像） |

### 5. 当前用户在某空间的权限

`GET /api/spaceUser/get?spaceId=xx`，权限：登录。

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-MEMBER-012 | 查询权限 | 创建者查询 | code=0，data.role=creator，data.permissions 为 admin 全量权限 |

响应 `data` 结构：

```json
{ "role": "creator", "permissions": ["picture:view", "picture:upload", "picture:edit", "picture:delete", "spaceUser:manage"] }
```

## 六、权限边界测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PERM-001 | viewer 查看 | viewer 调用 `spaceUser/list` | code=0（有 picture:view） |
| TC-PERM-002 | viewer 管理成员 | viewer 调用 `spaceUser/add` | code=40101（无 spaceUser:manage） |
| TC-PERM-003 | editor 管理成员 | editor 调用 `spaceUser/add` | code=40101 |
| TC-PERM-004 | admin 管理成员 | admin 调用 `spaceUser/add` | code=0（有 spaceUser:manage） |
| TC-PERM-005 | 私有空间越权 | 非创建者调用 `spaceUser/list` | code=40101 |
| TC-PERM-006 | 公共图库 | spaceId 为空，登录用户上传/查看 | code=0（公共权限） |
