# 阶段 5：以图搜图 —— 接口测试

> 本手册用于阶段 5 的手动接口测试与回归验证，配套自动化测试见文末「六、自动化测试」。
> 所有接口均以 `/api` 为上下文路径，登录态通过请求头 `satoken` 传递 token。
> 以图搜图涉及腾讯云 COS/数据万象 CI，测试前需按「二、测试环境准备」配置。

## 一、测试范围与约定

- 范围：以图搜图接口（腾讯云数据万象 CI 托管图片检索），以及上传后 CI 入库、删除后出库的一致性验证。
- 统一返回结构：

```json
{ "code": 0, "data": [], "message": "ok" }
```

- 错误码约定：

| 错误码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录 |
| 40101 | 无权限 |
| 40300 | 禁止访问 |
| 40400 | 请求数据不存在 |
| 50000 | 系统内部异常 |

## 二、测试环境准备

1. 启动 MySQL（库名 `cloud_gallery`，含 `picture` 表）。
2. 启动 Redis（端口 6379）。
3. 在 `application.yml` 配置真实 COS 密钥（`cos.secret-id` / `secret-key` / `bucket` / `region`）。
4. 数据万象已开通「内容识别」（含图像搜索），且已调用 `openImageSearch` 建立图库。
5. 启动服务：端口 8123，上下文路径 `/api`。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.19.10-hotspot'
mvn spring-boot:run
```

## 三、登录态获取（前置）

注册并登录，从登录响应 `data.token` 中取出 token，后续请求放入请求头 `satoken`。

```powershell
$base = "http://localhost:8123/api"

# 1. 注册
Invoke-RestMethod -Uri "$base/user/register" -Method Post -ContentType "application/json" `
  -Body '{"userAccount":"search_tester","userPassword":"12345678","checkPassword":"12345678"}'

# 2. 登录，获取 token
$login = Invoke-RestMethod -Uri "$base/user/login" -Method Post -ContentType "application/json" `
  -Body '{"userAccount":"search_tester","userPassword":"12345678"}'
$token = $login.data.token
```

文件上传 / 以图搜图使用 `curl.exe`（PowerShell 原生 `Invoke-RestMethod` 处理 multipart 较繁琐）：

```powershell
# 上传图片（为搜图准备素材）
curl.exe -X POST "$base/picture/upload" -H "satoken: $token" -F "file=@C:\path\to\a.png"

# 以图搜图
curl.exe -X POST "$base/picture/search/by/picture" -H "satoken: $token" -F "file=@C:\path\to\query.png"
```

## 四、以图搜图测试用例

### 1. 接口说明

`POST /api/picture/search/by/picture`，权限：登录（空间图片按 `picture:view` 校验，公共图库所有登录用户可搜）。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| file | multipart/file | 查询图片文件（与 fileUrl 二选一） |
| fileUrl | string | 查询图片 URL（与 file 二选一） |
| spaceId | long | 限定搜索空间 ID（空 = 公共图库） |
| topK | int | 返回最相似数量，默认 20 |

响应 `data` 为相似图片列表（`List<PictureVO>`，按相似度降序），元素结构与图片详情一致（`id/name/url/thumbnailUrl/picWidth/picHeight/picColor/spaceId/...`）。

### 2. 基础用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SEARCH-001 | 搜到相似图 | 先上传多张图，再用其中一张（或相似图）作为查询图 | code=0，返回非空列表，最相似（自身）排最前 |
| TC-SEARCH-002 | 空结果 | 用与图库完全不同的查询图搜索 | code=0，返回空列表 `[]` |
| TC-SEARCH-003 | 空间内搜索 | 指定 spaceId 搜索 | code=0，仅返回该空间图片 |
| TC-SEARCH-004 | 公共图库搜索 | spaceId 缺省 | code=0，仅返回公共图库（space_id 为空）图片 |
| TC-SEARCH-005 | 未登录 | 不带 token | code=40100 |
| TC-SEARCH-006 | file 与 fileUrl 均缺省 | 两者都不传 | code=40000 |
| TC-SEARCH-007 | 查询图格式非法 | 传 `.gif` 文件 | code=40000（本地解析失败） |
| TC-SEARCH-008 | topK 指定 | 传 topK=3 | code=0，返回数量 ≤ 3 |

### 3. CI 入库 / 出库一致性用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SEARCH-009 | 删除后不再命中 | 上传图片 → 删除该图片 → 再用其原图搜索 | code=0，结果中不再包含已删除图片（CI 图库已出库） |

## 五、权限说明

- 以图搜图接口仅要求登录（`@SaCheckLogin`）。
- 空间图片的查看权限在 Service 层按 `spaceId` 校验 `picture:view`；公共图库（spaceId 为空）所有登录用户可搜。
- 越权搜索他人私有空间图片 → code=40101。

## 六、自动化测试

已提供 JUnit 自动化测试，覆盖阶段 5 核心逻辑：

| 测试类 | 类型 | 用例数 | 对应范围 |
| --- | --- | --- | --- |
| `CiImageSearchStrategyTest` | 单元测试（mock CosManager） | 5 | CI 入库 / 出库 / 检索 / 临时对象清理 / 异常吞掉 |
| `CosImageSearchEndToEndTest` | 端到端测试（真实 CI） | 1 | 建图库 → 上传 → 入库 → 检索命中 → 出库 → 清理 |

运行常规测试（需 MySQL、Redis 已启动）：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.19.10-hotspot'
mvn test "-Dtest=CiImageSearchStrategyTest"
```

运行 CI 端到端测试（真实调用腾讯云图像搜索，会产生费用与 COS/CI 副作用，默认跳过）：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.19.10-hotspot'
$env:RUN_CI_E2E = 'true'
mvn test "-Dtest=CosImageSearchEndToEndTest"
```

测试文件位置：

- `src/test/java/com/ylum/cloudgallery/service/search/CiImageSearchStrategyTest.java`
- `src/test/java/com/ylum/cloudgallery/manager/CosImageSearchEndToEndTest.java`
