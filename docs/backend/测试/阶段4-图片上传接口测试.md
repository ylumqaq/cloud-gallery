# 阶段 4：图片上传 —— 接口测试

> 本手册用于阶段 4 的手动接口测试与回归验证，配套自动化测试见文末「九、自动化测试」。
> 所有接口均以 `/api` 为上下文路径，登录态通过请求头 `satoken` 传递 token。
> 上传接口会真实写入腾讯云 COS，测试前需配置真实密钥。

## 一、测试范围与约定

- 范围：图片上传（本地 / URL）、分页查询、详情、编辑、删除、批量抓取，以及公共图库 / 空间权限边界。
- 统一返回结构：

```json
{ "code": 0, "data": null, "message": "ok" }
```

- 错误码约定：

| 错误码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录 |
| 40101 | 无权限 |
| 40300 | 禁止访问 |
| 40400 | 请求数据不存在 |
| 50000 | 系统内部异常 |

## 二、测试环境准备

1. 启动 MySQL（库名 `cloud_gallery`，含 `picture` 表）。
2. 启动 Redis（端口 6379）。
3. 在 `application.yml` 配置真实 COS 密钥（`cos.secret-id` / `secret-key` / `bucket` / `region`）。
4. 启动服务：端口 8123，上下文路径 `/api`。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.19.10-hotspot'
mvn spring-boot:run
```

## 三、登录态获取（前置）

注册并登录，从登录响应 `data.token` 中取出 token，后续请求放入请求头 `satoken`。

```powershell
$base = "http://localhost:8123/api"

# 1. 注册
Invoke-RestMethod -Uri "$base/user/register" -Method Post -ContentType "application/json" `
  -Body '{"userAccount":"pic_tester","userPassword":"12345678","checkPassword":"12345678"}'

# 2. 登录，获取 token
$login = Invoke-RestMethod -Uri "$base/user/login" -Method Post -ContentType "application/json" `
  -Body '{"userAccount":"pic_tester","userPassword":"12345678"}'
$token = $login.data.token
```

文件上传使用 `curl.exe`（PowerShell 原生 `Invoke-RestMethod` 处理 multipart 较繁琐）：

```powershell
curl.exe -X POST "$base/picture/upload" -H "satoken: $token" -F "file=@C:\path\to\test.png"
```

## 四、图片上传测试用例

`POST /api/picture/upload`，权限：登录 + `@SaSpaceCheckPermission(picture:upload)`。`Content-Type` 为 `multipart/form-data`。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| file | multipart/file | 本地文件（与 fileUrl 二选一） |
| fileUrl | string | 网络图片 URL（与 file 二选一） |
| spaceId | long | 所属空间 ID（空 = 公共图库） |
| picName | string | 图片名称（可选，不传则用原始文件名） |
| category | string | 图片分类（可选，用于分类分析） |
| tags | string | 图片标签（可选，JSON 数组字符串，用于标签分析） |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PIC-001 | 本地上传公共图库 | 传 file，spaceId 缺省 | code=0，返回 id/url/thumbnailUrl/picWidth/picHeight/picFormat/picColor |
| TC-PIC-002 | URL 上传 | 传 fileUrl（如 `https://picsum.photos/200/200`） | code=0，返回图片信息 |
| TC-PIC-003 | 上传到私有空间 | 创建者传 spaceId | code=0，data.spaceId=空间 id |
| TC-PIC-004 | file 与 fileUrl 均缺省 | 两者都不传 | code=40000 |
| TC-PIC-005 | 文件格式非法 | 传 `.gif` 文件 | code=40000 |
| TC-PIC-006 | 文件超 2MB | 传大于 2MB 文件 | code=40000 |
| TC-PIC-007 | URL 协议非法 | fileUrl=`ftp://x/x.jpg` | code=40000 |
| TC-PIC-008 | 未登录 | 不带 token | code=40100 |
| TC-PIC-009 | 目标空间不存在 | spaceId 为不存在的 ID | code=40400 |

上传成功响应 `data` 示例：

```json
{
  "id": 2087914486554959874,
  "name": "test.png",
  "url": "https://bucket-1250000000.cos.ap-guangzhou.myqcloud.com/public/20260813/xxx.png",
  "thumbnailUrl": "https://bucket-1250000000.cos.ap-guangzhou.myqcloud.com/public/20260813/xxx_thumbnail.png",
  "picSize": 260,
  "picWidth": 100,
  "picHeight": 100,
  "picFormat": "png",
  "picColor": "0xe00000",
  "category": "头像",
  "tags": "[\"风景\",\"旅行\"]"
}
```

## 五、查询测试用例

### 1. 分页查询

`GET /api/picture/list/page/vo`，权限：登录（公共图库可看，空间图片按权限）。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| current | int | 当前页（默认 1） |
| pageSize | int | 每页大小（默认 10） |
| spaceId | long | 空间 ID（空 = 公共图库） |
| searchText | string | 名称关键词 |
| picColor | string | 主色调 |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PIC-010 | 公共图库分页 | spaceId 缺省 | code=0，data.records 为公共图库图片，data.total 正确 |
| TC-PIC-011 | 关键词搜索 | 传 searchText | code=0，仅返回名称匹配的图片 |
| TC-PIC-012 | 按颜色搜索 | 传 picColor | code=0，仅返回主色调匹配的图片 |
| TC-PIC-013 | 未登录 | 不带 token | code=40100 |

### 2. 图片详情

`GET /api/picture/get/{id}`，权限：登录（公共图库可看，空间图片按 view 权限）。

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PIC-014 | 查询详情 | 上传后传入图片 ID | code=0，返回完整图片信息 |
| TC-PIC-015 | 图片不存在 | 传入不存在的 ID | code=40400 |

## 六、编辑 / 删除测试用例

> 权限说明：公共图库图片（`space_id` 为空）仅上传者本人可编辑 / 删除；空间图片按空间角色权限校验。

### 1. 编辑图片

`POST /api/picture/edit`，权限：登录。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | long | 图片 ID |
| name | string | 新名称（非空，≤128） |
| spaceId | long | 目标空间（空 = 不移动空间；非空 = 移动到目标空间） |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PIC-016 | 上传者编辑名称 | 本人改名 | code=0，详情返回新名称 |
| TC-PIC-017 | 非上传者编辑 | 他人改名 | code=40101 |
| TC-PIC-018 | 移动到目标空间 | spaceId 传目标空间 | code=0，data.spaceId 更新 |
| TC-PIC-019 | 目标空间不存在 | spaceId 为不存在的 ID | code=40400 |

### 2. 删除图片

`POST /api/picture/delete`，权限：登录。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | long | 图片 ID |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PIC-020 | 上传者删除 | 本人删除 | code=0，同时删除 COS 原图 / 缩略图 / webp |
| TC-PIC-021 | 非上传者删除 | 他人删除 | code=40101 |
| TC-PIC-022 | 删除后再查详情 | 删除后调用 get | code=40400 |

## 七、批量抓取测试用例

`POST /api/picture/upload/batch`，权限：登录。用 Jsoup 爬取必应图片搜索结果，逐张走 URL 上传流程，单张失败不影响其他图片。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| searchText | string | 抓取关键词（非空） |
| count | int | 抓取数量 |
| spaceId | long | 目标空间（空 = 公共图库） |

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PIC-023 | 批量抓取 | 传 searchText、count | code=0，返回图片列表（数量 ≤ count） |
| TC-PIC-024 | 关键词为空 | searchText 缺省 | code=40000 |
| TC-PIC-025 | 未登录 | 不带 token | code=40100 |

## 八、权限边界测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PIC-026 | 公共图库上传 | spaceId 空，登录用户上传 | code=0（公共权限含 picture:upload） |
| TC-PIC-027 | 空间 viewer 上传 | viewer 调用 upload（spaceId=空间） | code=40101（viewer 无 picture:upload） |
| TC-PIC-028 | 空间 editor 编辑 | editor 编辑空间图片 | code=0（editor 有 picture:edit） |
| TC-PIC-029 | 空间 admin 删除 | admin 删除空间图片 | code=0（admin 有 picture:delete） |
| TC-PIC-030 | 公共图库非上传者编辑 | 他人编辑公共图库图片 | code=40101（仅上传者可操作） |

## 十、权限码与角色映射

权限配置见 `src/main/resources/spaceUserAuthConfig.json`：

| 角色 / 场景 | 权限码 |
| --- | --- |
| viewer | picture:view |
| editor | picture:view, picture:upload, picture:edit |
| admin | picture:view, picture:upload, picture:edit, picture:delete, spaceUser:manage |
| 公共图库（所有登录用户） | picture:view, picture:upload |
| 私有空间创建者 | 同 admin 全量权限 |
| 私有空间非创建者 | 无权限 |

公共图库图片的编辑 / 删除为「仅上传者本人可操作」（因公共图库权限码无 `picture:edit/delete`，由 Service 层 `checkPicturePermission` 单独处理）。
