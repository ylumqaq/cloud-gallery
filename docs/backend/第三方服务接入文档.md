# 云图库第三方服务接入文档

## 一、腾讯云 COS（对象存储）

### 1. 开通与准备

1. 注册腾讯云账号，开通「对象存储 COS」；
2. 创建存储桶，记录 `bucket`（存储桶名称）和 `region`（地域，如 `ap-guangzhou`）；
3. 在「访问管理 CAM」创建 API 密钥，获取 `SecretId` / `SecretKey`；
4. 记录 `AppId`（腾讯云账号 AppId）。

### 2. Maven 依赖

```xml
<dependency>
    <groupId>com.qcloud</groupId>
    <artifactId>cos_api</artifactId>
    <version>5.6.155</version>
</dependency>
```

### 3. 初始化 COSClient

```java
COSCredentials cred = new BasicCOSCredentials(secretId, secretKey);
ClientConfig clientConfig = new ClientConfig(new Region(region));
COSClient cosClient = new COSClient(cred, clientConfig);
```

### 4. 上传图片

```java
PutObjectRequest request = new PutObjectRequest(bucket, key, file);
PutObjectResult result = cosClient.putObject(request);
String url = cosClient.getObjectUrl(bucket, key).toString();
```

## 二、腾讯云数据万象 CI（图片处理 + 以图搜图）

### 1. 开通 CI

数据万象（Cloud Infinite，CI）与 COS 存储桶绑定开通，用于图片处理与智能检索。

### 2. 图片处理能力

通过 COS 对象 URL 追加处理参数（或 SDK）调用 CI：

| 能力 | 方式 |
| --- | --- |
| 压缩为 webp | `url?imageMogr2/format/webp` |
| 生成缩略图 | `url?imageMogr2/thumbnail/200x200` |
| 图片信息（宽高/格式/主色调） | `url?imageInfo` |

上传图片时一次性完成：webp 压缩、缩略图生成、宽高/格式/平均主色调提取。

### 3. 托管图片检索（以图搜图）

使用腾讯云数据万象 CI 的「图片搜索」能力（托管图片检索），应用侧**无需本地向量提取、无需 PostgreSQL / pgvector**：

- 上传成功后，调用 `addGalleryImage(原图对象键, 图片ID)` 把图片加入 CI 图库，`entityId` 保存图片 ID；
- 删除图片后，从 URL 解析对象键，调用 `deleteGalleryImage(对象键, 图片ID)` 出库；
- 以图搜图时，把查询图临时上传到 COS（临时键 `search/query/xxx`），调用 `searchGalleryImages(临时键, topK)` 返回图片 ID 列表，再回 MySQL 按 ID 查详情（空间过滤由 MySQL 兜底）。

## 三、配置项汇总

```yaml
cos:
  secret-id: 你的SecretId
  secret-key: 你的SecretKey
  app-id: 你的AppId
  bucket: 你的bucket名称
  region: ap-guangzhou
```

## 四、接入要点

- 密钥不要在代码里硬编码，建议通过环境变量或配置文件注入；
- 图片 URL 建议使用 HTTPS，存储桶可配合 CDN 加速访问；
- COS 负责「文件存储」，CI 负责「图片处理 + 以图搜图（托管图片检索）」，二者共用同一存储桶与密钥。
