# 云图库服务器部署文档

> 本文档总结前后端部署到 Linux 云服务器的完整流程（以 Ubuntu 24.04 为例）。
> 所有真实 IP、密码、密钥均已用占位符代替，请自行替换。

## 一、部署架构

```
用户浏览器
   │  http://<服务器公网IP>/
   ▼
Nginx（80 端口）
   ├── /        → 前端静态文件（dist 构建产物）
   └── /api/*   → 反向代理 → 后端 127.0.0.1:8123
```

后端 Spring Boot 依赖：

| 依赖 | 用途 |
| --- | --- |
| MySQL 8.0 | 业务库 `cloud_gallery` |
| Redis | 会话 / 缓存 |
| 腾讯云 COS + 数据万象 CI | 图片存储 + 以图搜图 |

以图搜图使用腾讯云数据万象 CI 托管图片检索（`addGalleryImage` / `deleteGalleryImage` / `searchGalleryImages`），全程**无需安装 PostgreSQL / pgvector**。

## 二、服务器环境准备

### 1. 安装 JDK 17

```bash
apt update
apt install -y openjdk-17-jdk-headless
java -version
```

### 2. 安装 MySQL 8.0

```bash
apt install -y mysql-server
systemctl enable --now mysql
```

初始化业务库与专用账号（`<数据库密码>` 自行设置）：

```sql
CREATE DATABASE IF NOT EXISTS cloud_gallery DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER IF NOT EXISTS 'cloud'@'localhost' IDENTIFIED BY '<数据库密码>';
GRANT ALL PRIVILEGES ON cloud_gallery.* TO 'cloud'@'localhost';
FLUSH PRIVILEGES;
```

导入建表 SQL（`backend/src/main/resources/sql/mysql_schema.sql`）：

```bash
mysql -u cloud -p'<数据库密码>' cloud_gallery < mysql_schema.sql
```

### 3. 安装 Redis

```bash
apt install -y redis-server
systemctl enable --now redis-server
redis-cli ping   # 返回 PONG
```

### 4. 安装 Nginx

```bash
apt install -y nginx
```

## 三、后端部署

### 1. 打包

```bash
mvn clean package -DskipTests
# 产物：target/cloud-gallery-1.1.0.jar
```

### 2. 上传并准备生产配置

将 jar 上传到服务器（如 `/opt/cloud-gallery/`），并在同目录放置 `application.yml`（基于 `application-example.yml` 修改，关键项见下）。

关键配置项：

```yaml
server:
  port: 8123
  servlet:
    context-path: /api

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/cloud_gallery?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: cloud
    password: "<数据库密码>"
    driver-class-name: com.mysql.cj.jdbc.Driver
  data:
    redis:
      host: localhost
      port: 6379

cos:
  secret-id: "<SecretId>"
  secret-key: "<SecretKey>"
  bucket: "<Bucket>"
  region: ap-guangzhou
```

### 3. 配置 systemd 服务

`/etc/systemd/system/cloud-gallery.service`：

```ini
[Unit]
Description=Cloud Gallery Backend
After=network.target mysql.service redis-server.service

[Service]
User=root
WorkingDirectory=/opt/cloud-gallery
ExecStart=/usr/bin/java -Xms256m -Xmx1024m -Dfile.encoding=UTF-8 -jar /opt/cloud-gallery/cloud-gallery-1.1.0.jar --spring.config.additional-location=file:/opt/cloud-gallery/application.yml
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

启动：

```bash
systemctl daemon-reload
systemctl enable --now cloud-gallery
journalctl -u cloud-gallery -f   # 查看启动日志
```

## 四、前端部署

### 1. 构建

```bash
cd frontend
pnpm install
pnpm build      # 产物：frontend/dist
```

### 2. 上传

将 `dist` 目录上传到服务器（如 `/opt/cloud-gallery/dist`）。

### 3. 配置 Nginx 反向代理

`/etc/nginx/conf.d/cloud-gallery.conf`：

```nginx
server {
    listen 80;
    server_name _;

    client_max_body_size 50m;

    root /opt/cloud-gallery/dist;
    index index.html;

    # 前端静态资源与 SPA 路由回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理（后端 context-path 为 /api）
    location /api/ {
        proxy_pass http://127.0.0.1:8123;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

重载：

```bash
nginx -t && systemctl reload nginx
```

## 五、一键部署脚本

为方便后续更新，项目本地提供两个 PowerShell 部署脚本（**已加入 .gitignore，含服务器 IP，不提交到仓库**）：

- 后端：`backend/deploy-server.ps1`（backend 目录）—— 打包 + 上传 jar + 重启服务
- 前端：`frontend/deploy-server.ps1` —— 构建 + 上传 dist

使用前提：已配置 SSH 免密登录（SSH config 别名 `cloud-gallery`）。

## 六、安全组放行

在云服务器控制台安全组放行入方向 `TCP 80` 端口。后端 `8123` 端口无需对外暴露（仅 Nginx 本地转发）。
