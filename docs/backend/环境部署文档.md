## 三、数据库初始化

### 1. MySQL（业务库，端口 3306）

- 创建数据库：

```sql
CREATE DATABASE cloud_gallery DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

- 建表：`user` / `space` / `space_user` / `picture`（详见《数据库设计文档》）。

## 四、Redis（端口 6379）

- 已安装运行（服务 Redis），默认 6379、无密码，可按需配置。

## 五、腾讯云 COS + CI 配置

需在腾讯云控制台获取：

- `secretId` / `secretKey`（访问密钥）
- `bucket`（存储桶名称）、`region`（地域）
- 开通数据万象 CI，用于图片处理与 CI 托管图片检索（以图搜图）

## 六、application.yml 关键配置

```yaml
server:
  port: 8123
  servlet:
    context-path: /api

spring:
  datasource:                                        # MySQL 业务库
    url: jdbc:mysql://localhost:3306/cloud_gallery?useUnicode=true&characterEncoding=utf8mb4&serverTimezone=Asia/Shanghai
    username: root
    password: 你的MySQL密码
    driver-class-name: com.mysql.cj.jdbc.Driver
  data:
    redis:                                           # Redis
      host: localhost
      port: 6379
  session:
    store-type: redis                                # Spring Session 分布式会话

# 腾讯云 COS / 数据万象 CI
cos:
  secret-id: 你的SecretId
  secret-key: 你的SecretKey
  bucket: 你的bucket
  region: ap-guangzhou

# Sa-Token
sa-token:
  token-name: satoken
  timeout: 2592000                                   # 30 天
  is-concurrent: true

# 分库分表（ShardingSphere，已启用）
```

## 七、启动步骤

1. 确保 JDK 17、MySQL、Redis 均就绪；
2. 初始化 MySQL 表结构；
3. 填写 `application.yml` 的数据库、Redis、COS 配置；
4. 构建并启动：

```bash
# 开发模式
mvn spring-boot:run

# 或打包运行
mvn clean package -DskipTests
java -jar target/xxx.jar
```

5. 验证：访问 `http://localhost:8123/api/...`，接口统一返回 `BaseResponse`。

## 八、接口文档（Knife4j）与接口测试

项目已集成 Knife4j（OpenAPI3），启动后可通过图形界面进行接口测试：

- 访问地址：`http://localhost:8123/api/doc.html`
- 底层 OpenAPI 描述：`http://localhost:8123/api/v3/api-docs`

### 测试步骤

1. 启动服务（见第七节），浏览器打开 `http://localhost:8123/api/doc.html`；
2. 在「用户模块」中先调用 `POST /api/user/register` 注册账号，或 `POST /api/user/login` 登录；
3. 登录接口响应 `data` 中会返回 `token`，将其复制；
4. 每个接口都内置了全局请求头参数 `satoken`，把第 3 步的 `token` 填入后，即可测试 `GET /api/user/get/login`、`POST /api/user/logout` 等需要登录的接口；
5. 接口统一返回 `BaseResponse` 结构：`code`（0 成功）、`data`、`message`。

> 说明：Knife4j 配置位于 `application.yml` 的 `knife4j` 节点；文档基本信息与全局 `satoken` 请求头参数在 `config/Knife4jConfig` 中配置。由于 Knife4j 4.5.0 自带的 springdoc 2.3.0 与 Spring Boot 3.5 不兼容，`pom.xml` 中已排除该传递依赖并显式升级为 springdoc 2.8.9，同时关闭 Knife4j 增强模式（`knife4j.enable: false`）。
