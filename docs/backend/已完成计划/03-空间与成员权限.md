**`space` 表结构**（建表 SQL）：

```sql
CREATE TABLE IF NOT EXISTS `space` (
    `id`          BIGINT       NOT NULL COMMENT '空间 ID（雪花 ID）',
    `space_name`  VARCHAR(128) NOT NULL COMMENT '空间名称',
    `space_type`  TINYINT      NOT NULL COMMENT '空间类型：0 私有 / 1 团队',
    `user_id`     BIGINT       NOT NULL COMMENT '创建者用户 ID',
    `create_time` DATETIME     NOT NULL COMMENT '创建时间',
    `update_time` DATETIME     NOT NULL COMMENT '更新时间',
    `is_delete`   TINYINT      NOT NULL DEFAULT 0 COMMENT '逻辑删除：0 未删除 / 1 已删除',
    PRIMARY KEY (`id`),
    KEY `idx_space_user_id` (`user_id`),
    KEY `idx_space_type` (`space_type`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_general_ci COMMENT = '空间表';
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT | 主键，雪花 ID（应用层生成） |
| `space_name` | VARCHAR(128) | 空间名称 |
| `space_type` | TINYINT | 空间类型：0 私有 / 1 团队 |
| `user_id` | BIGINT | 创建者用户 ID（索引 `idx_space_user_id`） |
| `create_time` | DATETIME | 创建时间 |
| `update_time` | DATETIME | 更新时间 |
| `is_delete` | TINYINT | 逻辑删除：0 未删除 / 1 已删除，默认 0 |

**`space_user` 表结构**（建表 SQL，成员关系为物理删除）：

```sql
CREATE TABLE IF NOT EXISTS `space_user` (
    `id`          BIGINT      NOT NULL COMMENT '成员关系 ID（雪花 ID）',
    `space_id`    BIGINT      NOT NULL COMMENT '空间 ID',
    `user_id`     BIGINT      NOT NULL COMMENT '用户 ID',
    `space_role`  VARCHAR(64) NOT NULL COMMENT '角色：viewer / editor / admin',
    `create_time` DATETIME    NOT NULL COMMENT '加入时间',
    `update_time` DATETIME    NOT NULL COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_space_user` (`space_id`, `user_id`),
    KEY `idx_space_user_user_id` (`user_id`)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_general_ci COMMENT = '空间成员表';
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT | 主键，雪花 ID（应用层生成） |
| `space_id` | BIGINT | 空间 ID（联合唯一键 `uk_space_user`） |
| `user_id` | BIGINT | 用户 ID（联合唯一键、索引 `idx_space_user_user_id`） |
| `space_role` | VARCHAR(64) | 角色：viewer / editor / admin |
| `create_time` | DATETIME | 加入时间 |
| `update_time` | DATETIME | 更新时间 |

### 4. 空间模块（服务层 + 控制层）

文件：`service/SpaceService.java`、`service/impl/SpaceServiceImpl.java`、`controller/SpaceController.java`（前缀 `/space`）

| 接口 | 方法 | 权限 | 说明 |
| --- | --- | --- | --- |
| `/space/add` | POST | 登录 | 校验空间类型，创建者为当前用户 |
| `/space/edit` | POST | 创建者或管理员 | 修改空间名称 |
| `/space/delete` | POST | 创建者或管理员 | 逻辑删除空间 + 物理删除成员关系 |
| `/space/get/{id}` | GET | 登录 | 空间详情 |
| `/space/list` | GET | 登录 | 当前用户创建的空间列表 |

关键实现：`edit` / `delete` 通过 `checkSpaceOwnerOrAdmin` 校验「创建者或系统管理员」，管理员判断基于 `UserConstant.hasAdminRole`（`admin` 或 `super_admin`）。

### 6. 空间权限体系（auth 包）

| 文件 | 职责 |
| --- | --- |
| `auth/SaSpaceCheckPermission.java` | 自定义空间权限校验注解 |
| `auth/SpaceUserAuthAspect.java` | AOP 切面，拦截注解并校验权限码 |
| `auth/SpaceUserAuthManager.java` | 权限核心：三种场景分支收敛 + 角色查询 |
| `auth/SpaceUserAuthConfig.java` | 权限配置 POJO |
| `auth/SpaceUserAuthContext.java` | 从请求上下文解析 `spaceId` |
| `resources/spaceUserAuthConfig.json` | 角色 → 权限码映射配置 |

权限收敛逻辑（`SpaceUserAuthManager.getPermissionList`）：

1. **公共图库**（spaceId 为空）→ 返回公共权限（`picture:view` + `picture:upload`）。
2. **私有空间** → 创建者拥有 admin 全量权限，其余用户无权限。
3. **团队空间** → 按成员角色映射权限码（viewer/editor/admin）。
