# 阶段 2：用户认证

## 目标

实现用户注册、登录、退出、信息脱敏，登录态存 Redis。

## 前置依赖

阶段 1（工程骨架）。

## 任务清单

- [ ] `user` 表实体 / Mapper / Service
- [ ] 注册接口（参数校验、账号唯一、密码加密）
- [ ] 登录接口（`StpUtil.login` + Redis 会话）
- [ ] 获取当前登录用户、退出登录
- [ ] 用户信息脱敏（不返回密码等敏感字段）

## 关键类

- `UserController`、`UserServiceImpl`、`UserMapper`
- `User`、`UserVO`（脱敏视图对象）
