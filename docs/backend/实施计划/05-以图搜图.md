# 阶段 5：以图搜图

## 目标

使用腾讯云数据万象 CI 托管图片检索实现「以图搜图」，打通「上传图片 → CI 入库 → 以图搜图 → 删除图片出库」完整链路，全程不依赖本地向量提取与 PostgreSQL。

## 前置依赖

阶段 4（图片上传）。

## 任务清单

- [ ] 封装 `CosManager` 的 CI 图库能力（`addGalleryImage` / `deleteGalleryImage` / `searchGalleryImages`）
- [ ] 上传图片成功后调用 `addGalleryImage(原图对象键, 图片ID)` 加入 CI 图库，`entityId` 保存图片 ID
- [ ] 删除图片后从 URL 解析对象键，调用 `deleteGalleryImage(对象键, 图片ID)` 出库
- [ ] 以图搜图接口（查询图临时上传 COS → `searchGalleryImages` 返回图片 ID → MySQL 回查详情）
- [ ] 空间过滤由 MySQL 兜底

## 关键类

- `PictureController`（以图搜图接口）
- `CosManager`（CI 图库入库 / 出库 / 检索封装）
- `CiImageSearchStrategy`（CI 托管图片检索）

## 验收标准

- 上传图片后成功加入 CI 图库
- 以图搜图能返回相似图片
- 删除图片后 CI 图库同步出库
