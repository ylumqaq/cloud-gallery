# 阶段 5：以图搜图

## 目标

实现图片向量提取、存储与相似度检索（MySQL + PostgreSQL 双库）。

## 前置依赖

阶段 4（图片上传）。

## 任务清单

- [ ] CI 图片向量特征提取集成
- [ ] 向量写入 PostgreSQL `picture_embedding`
- [ ] 以图搜图接口（pgvector 检索 `picture_id` → MySQL 回查详情）
- [ ] 删除图片时同步删除向量（双删）

## 关键类

- `PictureController`（以图搜图接口）
- `CosManager`（向量提取）
- `PictureEmbeddingMapper`（PostgreSQL 向量表）

## 验收标准

- 上传图片后向量成功写入 PostgreSQL
- 以图搜图能返回相似图片
- 删除图片后向量同步清理
