# 云图库测试文档

## 一、测试范围

覆盖关键接口与核心逻辑：用户认证、权限边界、图片上传、以图搜图、分表路由、统一返回/异常。

错误码约定见《API 接口文档》：`0` 成功、`40000` 参数错误、`40100` 未登录、`40101` 无权限、`50000` 系统异常。

## 二、用户认证测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-AUTH-001 | 注册成功 | 合法账号 + 密码 + 确认密码一致 | code=0，返回 userId |
| TC-AUTH-002 | 注册失败-账号重复 | 已存在账号注册 | 业务异常，提示账号已存在 |
| TC-AUTH-003 | 注册失败-密码不一致 | 密码与确认密码不同 | code=40000 |
| TC-AUTH-004 | 登录成功 | 正确账号密码 | code=0，返回 token + 脱敏用户信息 |
| TC-AUTH-005 | 登录失败-密码错误 | 错误密码 | 业务异常，提示密码错误 |
| TC-AUTH-006 | 获取当前用户 | 登录态请求 | code=0，返回脱敏信息（不含密码） |
| TC-AUTH-007 | 未登录访问 | 无 token 访问需登录接口 | code=40100 |
| TC-AUTH-008 | 退出登录 | 登录态退出 | code=0，会话失效 |

## 三、权限边界测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-PERM-001 | viewer 查看图片 | viewer 调用查看接口 | code=0（有 picture:view） |
| TC-PERM-002 | viewer 上传图片 | viewer 调用上传接口 | code=40101（无 picture:upload） |
| TC-PERM-003 | editor 编辑图片 | editor 调用编辑接口 | code=0（有 picture:edit） |
| TC-PERM-004 | admin 管理成员 | admin 添加成员 | code=0（有 spaceUser:manage） |
| TC-PERM-005 | editor 管理成员 | editor 添加成员 | code=40101（无 spaceUser:manage） |
| TC-PERM-006 | 私有空间越权 | 非创建者访问私有空间 | code=40101 |
| TC-PERM-007 | 公共图库越权 | 非作者修改公共图库图片 | code=40101 |

## 四、图片上传测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-UPLOAD-001 | 本地上传成功 | 上传合法图片（≤2MB，jpeg/png/webp） | code=0，返回图片信息，COS 有原图/缩略图 |
| TC-UPLOAD-002 | 文件过大 | 上传 >2MB 图片 | 校验失败，拒绝上传 |
| TC-UPLOAD-003 | 格式非法 | 上传 gif/txt | 校验失败，拒绝上传 |
| TC-UPLOAD-004 | URL 上传成功 | 合法图片 URL | code=0，下载并上传成功 |
| TC-UPLOAD-005 | URL 协议非法 | ftp:// 或非法协议 | 校验失败，拒绝（防 SSRF） |
| TC-UPLOAD-006 | 删除图片 | 删除已有图片 | code=0，COS 文件 + PG 向量同步清理 |

## 五、以图搜图测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SEARCH-001 | 搜到相似图 | 上传多张图后，用其中一张搜 | code=0，返回相似图片列表 |
| TC-SEARCH-002 | 空结果 | 用无相似图查询 | code=0，返回空列表 |
| TC-SEARCH-003 | 空间内搜索 | 指定 spaceId 搜索 | 仅返回该空间内图片 |
| TC-SEARCH-004 | 删除后清理 | 删除图片后再搜 | 已删图片不再出现在结果中 |

## 六、分表路由测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-SHARD-001 | 公共图库路由 | space_id 为空写入图片 | 数据落 `picture` 表 |
| TC-SHARD-002 | 团队空间路由 | space_id=1 写入图片 | 数据落 `picture_1` 表 |

| TC-SHARD-004 | 等值查询路由 | 按 space_id 等值查询 | 只命中对应分表 |

## 七、统一返回/异常测试用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TC-RESP-001 | 成功返回 | 任意成功接口 | 返回 BaseResponse，code=0 |
| TC-RESP-002 | 参数校验异常 | 缺必填参数 | code=40000 |
| TC-RESP-003 | 未登录异常 | 未登录访问 | code=40100 |
| TC-RESP-004 | 无权限异常 | 越权访问 | code=40101 |
| TC-RESP-005 | 系统异常 | 触发运行时异常 | code=50000，不泄露堆栈 |
